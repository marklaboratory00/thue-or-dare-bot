# 🎲 Бот «Правда или Действие» для Telegram-групп

Бот на **aiogram 3.x** для групп. Бот сам выбирает **двух случайных игроков**:
один спрашивает, другой отвечает или выполняет задание — и подкидывает случайную
«правду» или «действие». Никакого вебхука и домена не нужно — используется long
polling, деплой на Railway занимает пару минут.

> ⚠️ **Важно про Telegram:** Bot API не позволяет боту получить список всех
> участников группы (такого метода нет). Поэтому игроки сначала заходят в игру
> кнопкой **«✅ Участвую»** (или `/join`), а бот случайно выбирает пару уже из
> присоединившихся. Список хранится в памяти и сбрасывается при перезапуске бота
> — для вечеринки в одну сессию этого достаточно.

## Как играть

1. Кто-нибудь пишет `/game` или `/spin` — появляется меню.
2. Каждый участник жмёт **«✅ Участвую»** (нужно минимум 2 человека).
3. Жмёте **«🎲 Начать раунд»** — бот вытягивает случайную пару:
   *спрашивает @A → отвечает @B* и показывает вопрос/задание.
4. **«🎲 Следующий раунд»** — новая случайная пара. Кнопки «🗣 Правда» /
   «🔥 Действие» задают тип задания.

## Что внутри

| Файл | Назначение |
|------|-----------|
| `bot.py` | код бота (команды, кнопки, логика) |
| `questions.py` | списки вопросов и заданий — правьте под себя |

## Шаг 1. Создать бота в Telegram

1. Открой [@BotFather](https://t.me/BotFather).
2. Отправь `/newbot`, задай имя и username (должен заканчиваться на `bot`).
3. Скопируй **токен** вида `123456789:AAE...` — он понадобится дальше.

Чтобы бот в группе видел команды, оставь настройку **Group Privacy = ON**
(нам этого достаточно, т.к. используются команды и кнопки).

## Шаг 2. Залить проект на GitHub

Через сайт: создай новый пустой репозиторий и загрузи туда все файлы кнопкой
«Add file → Upload files».

Или через терминал:

```bash
git init
git add .
git commit -m "truth or dare bot"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/ТВОЙ_РЕПО.git
git push -u origin main
```

> ⚠️ Токен нигде в код не вставляй. Файл `.env` уже в `.gitignore`.

## Шаг 3. Задеплоить на Railway

1. Зайди на [railway.com](https://railway.com), войди через GitHub и **подтверди
   аккаунт** (без верификации у Railway ограничен исходящий трафик, и бот не
   сможет достучаться до Telegram).
2. **New Project → Deploy from GitHub repo** → выбери свой репозиторий.
   Railway сам определит Python и установит зависимости — Dockerfile не нужен.
3. Открой сервис → вкладка **Variables** → **New Variable**:
   - имя: `BOT_TOKEN`
   - значение: токен от BotFather
4. Дождись сборки (~1–2 мин). Открой вкладку **Logs** — там должно появиться
   `Бот запущен, начинаю polling…`.

Если Railway запустил сервис как `web` и ждёт порт, зайди в **Settings →
Deploy → Custom Start Command** и укажи:

```
python bot.py
```

## Шаг 4. Добавить бота в группу

1. Открой группу → «Добавить участника» → найди своего бота.
2. Напиши `/spin` (или `/start`) — появятся кнопки. Все жмут «✅ Участвую», затем «🎲 Начать раунд». Играйте!

## Как менять вопросы и задания

Открой `questions.py`, отредактируй списки `TRUTHS` и `DARES`, закоммить и
запушь в GitHub — Railway передеплоит бота автоматически.

## Запуск локально (для проверки)

```bash
pip install -r requirements.txt
export BOT_TOKEN="твой_токен"      # Windows: set BOT_TOKEN=твой_токен
python bot.py
```

## Команды бота

- `/start`, `/help` — приветствие и кнопки
- `/join` — войти в игру
- `/leave` — выйти
- `/players` — кто сейчас играет
- `/spin` — начать раунд (случайная пара)

## Частые проблемы

- **Бот молчит в логах / ошибки сети** → аккаунт Railway не верифицирован через
  GitHub, либо не задан `BOT_TOKEN`.
- **`Unauthorized`** → неверный токен.
- **В группе не реагирует на команды** → добавь бота в группу заново; проверь,
  что пишешь именно команду (можно `/spin@username_бота`).
- **«Нужно минимум 2 игрока»** → участники ещё не нажали «✅ Участвую» / `/join`.
- **После перезапуска бот «забыл» игроков** → список хранится в памяти, это норма;
  просто зайдите в игру заново.
- **Бесплатный лимит** → у Railway пробный кредит ограничен; для работы 24/7
  может понадобиться платный тариф.
